# 数据源与凭证策略

> 本文件规定「哪些东西可以进仓库、哪些必须留在本机」。
> 核心原则一句话：**代码进仓，凭证与本机配置绝不进仓；数据不进仓。**

---

## 1. 凭证：只允许以变量名出现

本项目的全部数据源都依赖使用者**自己的账号**。仓库内绝不出现任何取值，只允许出现变量名。

| 数据源 | 凭证载体 | 本仓库内的写法 |
|---|---|---|
| 东方财富妙想（mx-ds-mcp / mx-data） | `em_api_key` / `MX_APIKEY` | `os.getenv("MX_APIKEY")` |
| 同花顺 iFinD MCP | MCP 连接器内托管 | 代码不接触，由 MCP 层注入 |
| 通达信（tdx-connector） | 本地客户端 | 无凭证 |
| 腾讯自选股（westock-mcp） | MCP 连接器内托管 | 代码不接触 |

### 凭证存在哪里

- **首选**：环境变量（跨机器、可被 `.env.example` 说明而不泄露）。
- **MCP 客户端配置**：由客户端自己管理，不同客户端位置不同。部分脚本（如
  `fetch_pb_mcp_http.py`）会在运行时从客户端的标准配置位置读取 `em_api_key`，
  读不到则回退到环境变量 `EM_API_KEY`；配置文件位置可用 `XYD_MCP_JSON` 覆盖。
  **这些配置文件已在 `.gitignore` 中永久排除**，且不属于本仓库内容。

### 硬性规则

1. 任何密钥**不得**出现在 `.py` / `.json` / `.md` / 提交信息 / Issue / PR 描述里。
2. 一旦某密钥进入过 git 历史，即视为**已泄露**——即使后来删掉，`git log -p` 仍可翻出。
   处置方式只有一个：**到服务商后台吊销并重新签发**，而不是「删掉文件再提交一次」。
3. 提交前统一跑：
   ```bash
   python scripts/check_no_secrets.py
   ```
   启用钩子后（`git config core.hooksPath .githooks`）每次 `git commit` 自动执行，命中即阻断。

## 2. 数据：不入仓

`data/` 目录整体被 `.gitignore` 排除，原因有二：

- **体积**：`data/raw` 4.7MB、`data/index_daily_pb` 1.5MB，且会随刷新持续增长。
- **分发权**：`data/raw` 来自妙想 / 东财，`index_daily_pb`、`index_daily_pe` 来自东财 / 同花顺 / 国证。
  这些数据的**再分发权不在本项目手里**，公开仓库携带它们存在违反供应商条款的风险。

另外 `data/` 下有 4 个临时取数脚本（`stage1_build.py`、`fetch_index.py`、`probe_mx.py`、`test_fetch.py`）
写死了本机绝对路径与本地会话 UUID，按「个人路径不入仓」一并排除。

### 边界说明：根目录的示例序列

根目录的 `H30035.CSI.json` 是**单只指数**的日频估值序列，被 `cases_3etf_*.json`
等示例用例直接引用，属于「让 demo 跑得起来的最小输入」，不是批量数据。
它与 `data/` 下的全市场序列性质不同：前者用于演示、单只、单条序列可公开查证；
后者是供应商数据资产，整体排除。如果要接入自己的数据，请放 `data/`（已被忽略），
不要加到仓库根目录。

### 想让别人也能跑，怎么办

不要附带数据，而是提供**取数入口**：使用者用下面的公开方案自行拉取，缓存到本地 `data/`。

## 3. 公开可用的数据方案（可写进公开仓库的部分）

本节列出的都是**公开开源项目 / 官方渠道**，与个人账号无关。仓库对外说明数据来源时，
只引用这一层，不引用任何本机 MCP 配置或私有密钥。

| 方案 | 形态 | 覆盖 | 说明 |
|---|---|---|---|
| [a-stock-data](https://github.com/simonlin1212/a-stock-data) | Skill / 内嵌代码 | A 股行情、K 线、研报、资金面、公告、打板、期货、宏观 | 直连腾讯 / 东财 / 同花顺 / 新浪 / 巨潮 / 交易所官方，除 iwencai 外全部零 key；本项目的公开取数示例优先参考它 |
| [AKShare](https://github.com/akfamily/akshare) | Python 库 | 极广（股 / 债 / 期 / 基金 / 宏观） | 社区维护，接口多但有变动风险 |
| [Tushare](https://github.com/waditu/tushare) | Python 库 + 积分制 |  A 股基础与财务 | 需注册获取 token，属「个人凭证」，仅放环境变量 |
| [Baostock](https://github.com/baostock/baostock) | Python 库 | 估值历史、停牌、ST、退市日 | 免注册免 key，适合做历史估值序列 |
| [Qlib](https://github.com/microsoft/qlib) | 框架 + 数据脚本 | 量价与因子 | 含官方数据采集脚本 |
| 交易所 / 中证 / 国证 官方文件 | HTTP | 指数成分与权重、交易日历、期货日行情 | 一手权威源，注意访问频率 |

> 各项目的许可证以其仓库 `LICENSE` 为准；引用时请保留出处与署名。

**接入契约**：本项目对数据层只要求「按代码返回日期序列」，具体从哪来由使用者决定。
这也是为什么数据不进仓库——换源不应该改动引擎。

## 5. 新增数据源时的检查清单

- [ ] 凭证走 `os.getenv(...)`，没有字面量默认值
- [ ] 代码注释里没有出现真实 key（示例用 `<YOUR_KEY>` 占位）
- [ ] 打印 / 日志不输出完整 key（要输出就先脱敏）
- [ ] 拉到的大文件写进 `data/`（已被忽略），不落在仓库根目录
- [ ] 跑一遍 `python scripts/check_no_secrets.py`，通过再提交
- [ ] 若是第三方数据，确认其条款允许「仅本地使用、不再分发」
